## STOCK PORTFOLIO TRACKER

This is a simple Python project made as part of my CodeAlpha Python Programming Internship.
The program calculates the total investment in stocks using predefined stock prices.

## Features
- Shows the available stock symbols.
- Takes stock symbols and quantities as input.
- Checks whether the stock symbol and quantity are valid.
- Calculates the investment for each stock.
- Displays the total investment.
- Saves the portfolio details in a CSV file if the user wants to.

## Stock Prices
- AAPL: 180
- TSLA: 250
- GOOGL: 170
- MSFT: 420

These prices are predefined in the code and are not live market prices.

## Requirements
- Python 3
- VS Code or any Python editor

## How to Run
1. Open the project folder.
2. Open the terminal.
3. Run the following command:

   `stock_tracker.py`

## Output
The program displays the selected stocks, quantities, prices, individual investment values, and total investment. If the user chooses to save the results, a `portfolio.csv` file is created.
