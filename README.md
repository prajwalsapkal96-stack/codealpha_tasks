# HANGMAN GAME

This is a simple Hangman game made with Python.

The game chooses a word, and the player guesses it one letter at a time. There are six chances to guess incorrectly.

# How to play

1. Run `hangman.py`.
2. Guess the hidden word one letter at a time.
3. You have six incorrect guesses before the game ends.

# Features

- Randomly selects a word from a small list.
- Displays the word as blanks until letters are guessed.
- Shows a Hangman drawing that changes after incorrect guesses.
- Checks for invalid and repeated guesses.

# Requirements

- Python 3
- No additional packages

# Concepts used

- `random` module
- Lists and loops
- Conditions and input validation
